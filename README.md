# 📊 Stock Market Sentiment Analyzer

An AI-powered full-stack web application that analyzes real-time stock news sentiment using FinBERT and generates detailed market insights using Gemini API.

---

## 🚀 Features

- 🔎 Search company by name
- 📰 Fetch latest news using News API
- 🤖 Sentiment classification using FinBERT (Positive / Negative / Neutral)
- 📊 Interactive Pie Chart visualization
- 📋 Executive AI Summary
- 📈 Market Impact & Trend Analysis
- ⚠️ Risk Factors & Opportunities
- 📊 Quick Stats Dashboard
- 🔄 Loading & Error Handling States

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/stock-market-sentiment-analyzer.git
cd stock-market-sentiment-analyzer
```

---

### 2️⃣ Install Dependencies

Frontend:

```bash
cd client
npm install
```

Backend:

```bash
cd server
npm install
```

---

### 3️⃣ Setup Environment Variables

Create a `.env` file in server folder:

```
NEWS_API_KEY=your_news_api_key
HF_API_KEY=your_huggingface_api_key
GEMINI_API_KEY=your_gemini_api_key
```

---

### 4️⃣ Run the Application

Backend:

```bash
npm start
```

Frontend:

```bash
npm run dev
```
